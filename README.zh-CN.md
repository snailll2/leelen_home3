用于 Home Assistant 的立林（Leelen）3.0 智能家居集成，走的是立林官方 App
同款云服务（`iot.leelen.com`）。

集成 domain：`leelen3` · iot_class：`cloud_push`

## 功能

### 空调 — 中央空调（服务类型 8259）

- 模式：关闭 / 制热 / 制冷 / 送风 / 除湿
- 目标温度 5–35 °C，步进 1 °C；风速低 / 中 / 高三档
- 当前温湿度自动取自同房间的温控面板传感器
- 原始风速档位通过 `leelen_wind_speed` 状态属性暴露

### 地暖（服务类型 8268）

- 模式：制热 / 关闭，目标温度 5–35 °C
- 当前温度取自匹配的温控面板传感器

### 新风系统（服务类型 8261 / 8267）

- 开关 + 三档风速，对应 33 % / 66 % / 100 % 百分比
- 预设模式：低 / 中 / 高

### 灯光（服务类型 8212 / 8291 / 8292 / 8293 / 8305 / 8306 / 8314 / 8330 / 8456 / 8459）

- 所有灯具类型均支持开关
- 可调光灯具（调光筒灯 / 射灯、0-10V、磁吸、滑轨、双色灯）支持亮度
  （0–100 % level 档）
- 支持色温的灯具可调色温（2700–6500 K）
- RGB 调光灯与磁吸轨道灯支持 RGB 彩色

### 开关 / 插座（服务类型 8243 / 8270 / 8295 / 8309 / 8333 / 8491 / 8200 / 8201 / 8202）

- 智能插座、单通道动态面板、电磁阀、阀门、声光报警、净水器以开关实体呈现
- 空开断路器同样以开关实体呈现；其开关值为 base64 字节流格式
  （`//8=` 开、`AAA=` 关）

### 窗帘（服务类型 8232 / 8294 / 8317 / 8320）

- 开 / 关 / 停止 + 位置（0–100 %），走窗帘 action 与 position FIID
- 百叶帘额外支持叶片角度（tilt）

### 温控面板传感器（服务类型 8272 / 8246 / 8289）

- 每个发现的面板或温湿度传感器生成一个温度实体（°C）和一个湿度实体（%）
- 这些数值同时供同房间的空调 / 地暖实体使用

## 状态同步机制

集成通过三层机制保证设备状态实时：

1. **REST 快照** — 启动时及拓扑变化后，通过一次批量请求读取所有 FIID 状态。
2. **MQTT 推送（自动启用，推荐）** — 凭据按官方 App 方式自动从登录信息生
   成，集成会订阅官方 App 同款的 `lliot/fiids_report/{did}/{siid}` 主题，设备上报近实时到达。
3. **控制确认** — `encryptV1CtrlFIIDS` 只是"排队"下发指令（响应中的
   `waitNum`/`waitTime` 表示网关尚未执行）。因此发送指令后，集成会等待设备
   上报与指令一致的状态（按云端 `waitTime` 提示，上限 10 秒），并在指令等待
   期间（最长 60 秒）拒收过期的旧状态上报——避免界面回退到"指令前"的状态，
   也就是常被反馈的"状态慢一拍"问题。

REST 轮询兜底：MQTT 未连接时每 30 秒同步一次；MQTT 已连接时每 5 分钟做一次
后台刷新。

## 账号与令牌

- 登录只需立林手机号 + 短信验证码，无需账号密码。
- 令牌采用"提前刷新 + 惰性兜底"双保险：到期前 10 分钟主动刷新；若云端仍
  拒绝请求（10001），自动刷新并重试。并发刷新去重并带 20 秒冷却，轮换后的
  refreshToken 绝不会被重复上送（这是"莫名其妙被登出"的最常见原因）。新令
  牌持久化保存到配置项，重启无需重新登录。
- 设备标识（terminalId）跨重启持久化，与官方 App 一致，不再每次启动随机生成。
- 若 `refreshToken` 本身过期，集成会触发重新认证流程：确认手机号 → 输入新
  短信验证码即可。

## 安装

### HACS（推荐）

1. 在 Home Assistant 中打开 HACS。
2. 进入"集成"→ 点击右下角"+"。
3. 搜索 "Leelen Home"，或添加自定义仓库：
   - 仓库地址：`https://github.com/snailll2/leelen_home3`
   - 类别：Integration
4. 点击"下载"。HACS 会按 manifest 中的 domain 自动安装为
   `custom_components/leelen3`。
5. 重启 Home Assistant。

### 手动安装

1. 将本仓库的 `custom_components/leelen_home3` 目录复制到 Home Assistant 的
   `config/custom_components` 下，**并重命名为 `leelen3`** —— Home
   Assistant 按目录名解析自定义集成，而本集成的 domain 是 `leelen3`。
2. 重启 Home Assistant。

## 配置

1. 进入 **设置** → **设备与服务**。
2. 点击 **添加集成**，搜索 "Leelen Home3" / "立林3.0"。
3. 输入立林 App 绑定的手机号，系统发送短信验证码。
4. 输入验证码完成登录，配置项标题会显示家庭组名称，例如
   `家庭组：我的家(138xxxxxxxx)`。

### 选项

集成选项中有两个菜单：

- **MQTT** — 凭据**自动获取**，与官方 App 完全同款：用户名由账号生成
  （`a5e4x84a:<accountId>`），密码使用当前 accessToken，clientId 由云端
  refreshToken 接口响应下发。无需手动填写。两项都填写时以手动值优先；全部
  留空即保持自动模式。
- **刷新设备** — 重新从云端读取设备拓扑：为新增设备创建实体，移除已在立林
  App 中删除的设备实体，展示增删统计并重载集成。在立林 App 中增删设备后使
  用。

## 支持的设备

| Home Assistant 平台 | 立林逻辑服务 | 服务类型 |
|---|---|---:|
| climate | 中央空调（含当前温湿度） | 8259 |
| climate | 地暖（含当前温度） | 8268 |
| fan | 新风系统 | 8261, 8267 |
| light | 灯光：开关 / 调光 / 色温 / RGB | 8212, 8291–8293, 8305, 8306, 8314, 8330, 8456, 8459 |
| switch | 智能插座、动态面板、阀门、声光报警、净水器 | 8243, 8270, 8295, 8309, 8333, 8491 |
| switch | 空开断路器（base64 开关值） | 8200, 8201, 8202 |
| cover | 窗帘电机（含百叶帘角度） | 8232, 8294, 8317, 8320 |
| sensor | 温控面板与温湿度传感器 | 8272, 8246, 8289 |

服务类型编号与官方 App 的 `IotDeviceServiceType` 常量一致。其余立林服务
（智能终端、背景音乐、梯控、紧急按钮、门锁等）暂不支持。

## 常见问题

### 无法连接 / 登录失败

- 确认 Home Assistant 所在网络可以访问立林云端（`iot.leelen.com`）。
- 确认账号已在立林 App 中绑定网关设备。
- 若提示 refreshToken 已过期，按重新认证流程输入短信验证码；未存储
  `refreshToken` 的老版本配置需删除集成后重新添加。

### 设备不显示

- 在集成选项中执行 **刷新设备**。
- 检查设备在立林 App 中是否在线。
- 仅上表列出的逻辑服务类型会创建实体。

### 状态更新不及时

- MQTT 凭据自动获取；查看日志中的凭据获取记录，或重启 HA 触发一次令牌刷新。
- 未配置 MQTT 时依赖 30 秒 REST 轮询；指令状态在设备上报新状态后立即确认。
